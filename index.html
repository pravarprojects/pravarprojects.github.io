SAR Injestion & Detection Platform

An internal platform that lets analysts injest SAR scenes quickly and consistently. I designed and built it end to end: the map-based annotation UI, the APIs, the GPU inference service and the scene catalogue.

  • Model-assisted annotation: a trained detector proposes objects and analysts accept or correct them.
  • Semi-automatic placement tools that use the regular geometry of real-world scenes, so one action injests many targets.
  • Inference isolated in its own service with no database access, so it can be restarted, scaled or swapped without touching stored data.
  • Every annotation goes through one write path with an audit trail, whether hand-drawn or model-proposed.

MSTAR SAR Target Classifier

96.6%test accuracy on 2,425 held-out chips · 10 vehicle classes · 1.4 MB model

A compact CNN for automatic target recognition on radar chips. Test data is imaged at a different depression angle than training (15° vs 17°), a real operational distribution shift. SAR isn't a photo, so I went single-channel and dropped rotation augmentation, which creates physically impossible radar returns.

Error analysis drove the fixes: the confusion matrix showed one dominant false-positive class, and scaling model capacity cut errors from about 237 to about 84. The errors that remain are confident mistakes between physically similar armoured vehicles, the failure mode that matters most in deployment.

Open-Vocabulary Object Counting on Satellite Imagery

A web app that detects and counts any object an analyst describes in plain text across large satellite scenes, the automated feature-extraction pattern behind vessel and vehicle detection. I built the detection service: tiling large GeoTIFFs, running GPU inference per tile, and mapping results back to geographic coordinates.

We tested a vision-language-model approach and dropped it for a dedicated counting model, which gave more reliable counts.
